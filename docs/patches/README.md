# Minotaur v0.4 — hotfix 1

Небольшой ресурсный патч для Windows-пакета из
[run38784738765](https://github.com/Plane-PPP/openyamm/actions/runs/38784738765),
source SHA `385a1e447aadb17cdf3b0db36691a92889f23786`.
Проверить SHA можно в BUILD-REVISION.txt рядом с openyamm.exe.

## Установка

1. Закрыть игру.
2. Распаковать Minotaur-v0.4-hotfix-1.zip **в папку с openyamm.exe**.
   Должен появиться файл `assets/assets.zip`, рядом с прежним `assets/engine.zip`.
3. Если `assets/assets.zip` уже существует от другого мода/патча, сохранить его копию:
   этот hotfix не объединяет сторонние изменения. В исходном целевом пакете этого файла нет.
4. Запустить игру обычным способом. Настройки и сохранения не заменяются.

Не заменять engine.zip маленьким архивом! Игра сама монтирует assets.zip как overlay
перед engine.zip. Для отката убрать только установленный assets/assets.zip (либо вернуть
ранее существовавший файл из копии). Повторная установка того же патча идемпотентна.
BUILD-REVISION.txt остаётся ревизией executable; установленный патч отмечает отдельный
MINOTAUR-HOTFIX-1.json. Другие сборки не проверялись на совместимость с этим патчем.

## Что исправлено

- LS-001: новые темы имеют правильную схему и появляются в диалоге.
  Expert у Silk Nightwalker (Expert Perception), Master у Robert Morningstar (Master Mace),
  GM у Garic Senjac (GM Axe). Прежние услуги сохранены.
- LS-002: HP/SP/AC/Damage Resistance расположены в четыре строки внутри прежней рамки.
  Condition/Quick Spell возвращены на прежние позиции. Earth/Mind/Body больше не имеют
  одинаковую координату Y. Формулы и значения характеристик не изменены.

## Проверка в игре

Выбрать минотавра и подготовить золото: `gold set 100000`.
После каждого `goto` дождаться загрузки карты, затем выполнить `event`.

| Ранг | Подготовка навыка | Карта | Открыть дом | Требование |
| --- | --- | --- | --- | --- |
| Expert | `skill set LethalStrike 4 1` | `goto 3` | `event 31` | 2000 gold |
| Master | `skill set LethalStrike 7 2` | `goto 5` | `event 13` | 5000 gold |
| GM | `skill set LethalStrike 10 3` | `goto 35` | `event 225` | MinotaurLord,8000 gold |

Для GM требуется спасённое логово. Только в тестовой копии save можно выполнить
`qbit set 23` и `player class MinotaurLord`; эти команды обходят сюжетное развитие.
Проверить новый пункт Lethal Strike, повышение через него, списание золота и сохранность
старого Perception/Mace/Axe. Обычный Minotaur не должен получать GM.

Открыть Stats: проверить четыре строки HP/SP/AC/DR внутри рамки, Condition/Quick Spell ниже,
все шесть раздельных строк сопротивлений справа и RMB старых/новой характеристики.
Для MinotaurLord20 ожидается16%, Lord50 —22%, Minotaur50 —15%.

## Проверки и ограничения

Automatically tested: загрузка реальных тем, диалоговые действия/повышение/классовый cap,
непересечение строк и рамки, совпадение label/value, приоритет overlay и сохранность
остальных ресурсов engine.zip. Исходный PNG фона просмотрен для сверки границ.
Ручная визуальная проверка нового патча в Windows ещё не выполнена.
Executable и CI не менялись; полная Windows-пересборка для этого патча не требуется.

Генерация из репозитория: `python3 tools/package_minotaur_hotfix.py`.
Архив детерминированный; JSON содержит SHA256 overlay и трёх изменённых ресурсов.
