## Принятые решения

- Не менять сопротивление минотавра, Sword, Dagger, формулы Armsmaster и младшие ступени Axe.
- Новый GM Recovery сохраняет Expert-бонус и добавляет −1 tick за фактический уровень Axe.
- Axe применяется к любому персонажу с нужным мастерством; ограничения классов/рас сохраняются.
- Не удваивать elemental и независимые on-hit источники.
- Один полноценный следующий Windows-пакет; без промежуточных многогигабайтных сборок.

## Дальнейшее развитие Lethal Strike → Death Strike

Death Strike — уточнённое название и концепция прежнего Lethal Strike; второй конкурирующей
способности нет. Статус: **Proposed, формула v0.2 проектируется**, не реализовано.
Уникальный навык игрового минотавра, обычные очки навыков и четыре ранга мастерства.
Один trial после успешной завершённой melee-атаки любого оружия, если обычный урон ещё не убил;
не для misses, shooting или spells. Учитываются уровни персонажа/монстра.
С Expert — Perception и **личный** Identify Monster против лично изученной разновидности.
NORMAL допускает trial при любом положительном HP; GIANT только ниже половины runtime MaxHP,
с множителем0.25. Отдельное видимое сообщение успеха, без повторной смерти/XP/loot.

| Ранг | P0, % |
| --- | --- |
| Normal | `0.30*S` |
| Expert | `0.45*S + 0.14*V + 0.07*I` |
| Master | `0.55*S + 0.16*V + 0.08*I` |
| GM | `0.65*S + 0.18*V + 0.09*I` |

`delta=PlayerLevel-MonsterLevel`; при delta≥0 `KL=min(1.4,1+delta/60.0)`, иначе
`KL=30/(30+1.5*abs(delta))`; `P=min(15,P0*KL*KG)`, дробная точность.
Чужое знание Master не подменяет личный I в Death Strike.
Полный контракт, UI messages, hooks, открытые решения: [Death Strike](design/death-strike.md).

## Identify Monster

Статус: **Proposed / Research**, расширение существующего навыка, без замены оригинальных effects,
описаний, обучения, class caps и просмотра. Описанные ступени: N HP/AC, E attacks/damage,
M spells, GM resistances. Исследование выявило: нынешний renderer показывает все эти поля
без mastery gating; этот существующий просмотр сейчас сохраняется, исправление требует отдельной задачи.

Новое намеренное постоянное изучение A/B/C каждым персонажем. Дополнительные bonuses только
против изученной разновидности: N +I AC; E +I melee/shooting/spell damage; M распространяет
AC/damage на активную партию; GM даёт I% на ×2 spell damage на цель за применение.
Личные/командные источники выбираются независимыми максимумами, без суммирования.
Знание сохраняется между сессиями и при выходе из партии.

Дизайнерское решение Minotaur: максимум **Expert**, не повышать до M/GM. Пользователь подтвердил
Expert в игре, но текущие class/race таблицы дают Minotaur и Lord None; происхождение расхождения
не установлено. Lord не расширяется без отдельного согласования. Necromancer/Lich текущего
base cap **Master**, поэтому роль командного исследователя и мага возможна, естественный GM пока нет.
Nosferatu и Dragon race5 могут дать GM без изменения caps; остальные классы сохраняются.
Матрица доступности и технический порядок: [Identify Monster](design/identify-monster.md).
