# Каталог кукол: базовые персонажи для пака

Справочник к [ТЗ](README.md), этап D. Codex показывает пользователю строки этого каталога, отфильтрованные по полу
и расе персонажа, с тремя рекомендациями и листом картинок тел.

Источник: `assets_dev/engine/data_tables/character_data.txt`, строки с `Available at start` = `x` (только их игра
предлагает при создании партии; портрет предлагается там же, где его базовая строка). Строки 9001–9024 (герои MM9) —
те же тела-доноры с головами MM9, как база не нужны. Картинки тел — `assets_dev/engine/icons_x2/<тело>.png`. В частичном
клоне их обычно нет; этап 0 кладёт нужные в `$PACKS/_cache/dolls/` (см. README, раздел 4).

## Что задаёт выбранная строка (`base_character`)

| Что | Откуда | Можно ли поменять |
|---|---|---|
| Тип куклы, поза, место снаряжения | строка | нет: от типа зависят все картинки снаряжения |
| Тело и **руки** (с цветом кожи рук) | строка; пак заменяет только `body.png` | руки не перекрашиваются — кожа персонажа должна быть близка к коже донора |
| Раса (расовые навыки) | строка | нет |
| Класс и голос по умолчанию | строка | да, при создании партии |
| Где портрет предлагается | раса, классы и мир строки | строки мира, данных которого нет в установке, игра убирает |

## Не каждая голова подходит к каждому телу

Пересадка сохраняет **размер лица донора**: так задумано, иначе шлемы сядут не на голову. Масштабировать голову при
сборке нельзя. Поэтому, как крупно голова персонажа будет смотреться на кукле, решают два множителя:

- **лицо донора** относительно плеч — у тел оно заметно разное (таблица ниже);
- **объём волос персонажа** — пышные волосы или большая борода добавляют до четверти ширины, короткая стрижка не
  добавляет ничего.

Пример (2026-11-19): David с короткой стрижкой на `pc07` (мелкое лицо) в игре выглядел маленькоголовым рядом с `pc01`,
хотя пересадка точно повторила размер головы `pc07`. Сам `pc01` кажется крупноголовым только из-за кудрей и бороды.

Размер лица донора — ширина кожи лица к ширине плеч, замер по телам каталога, проверено глазами:

| Класс | Мужчины, тип 0 | Женщины, тип 1 |
|---|---|---|
| **крупное** | `mlfbod` 48, `mlcbod` 42, `mlhbod` 44, `mlbbod` 40, `pc35bod` 36, `mlgbod` 49 | `grlabod` 39, `grldbod` 45, `pc31bod` 32, `pc32bod` 34 |
| **среднее** | `mlebod` 47, `7pc02bod` 52, `7pc01bod` 50, `pc33bod` 33, `mldbod` 46, `mlabod` 38, `7pc04bod` 54 | `pc06bod` 6, `pc36bod` 37, `pc08bod` 8, `pc02bod` 2 |
| **мелкое** | `pc07bod` 7, `pc03bod` 3, `pc09bod` 9, `pc11bod` 11, `pc34bod` 35, `pc05bod` 5, `pc01bod` 1 | `7pc07bod` 53, `pc20bod` 20, `pc12bod` 12, `grlbbod` 41, `pc18bod` 18, `7pc05bod` 51, `pc04bod` 4, `grlcbod` 43, `7pc08bod` 55, `7pc20bod` 59 |
| не измерено (кожа не человеческого цвета) | вампиры 13, 15; тёмные эльфы 17, 19; гоблины 56, 58 | вампиры 14, 16; `pc10bod` 10; гоблин 57 — оценить глазами на листе голов |

Число — строка `character_data.txt`. Гномы (тип 4) — все четыре тела с лицом одного размера.

Какие тела предлагать, по волосам персонажа на мастере `face/final/01.png`:

| Волосы и борода персонажа | Предлагать | Не предлагать |
|---|---|---|
| короткие, прижатые, без бороды | только **крупное** | среднее и мелкое — голова будет мала |
| средние (до ушей и челюсти) или небольшая борода | крупное, среднее | мелкое |
| пышные, длинные или большая борода | любое | — |

Тела, которые не подходят, в рекомендации и общий список остановки 2 не попадают. Если пользователь сам называет
такое тело, предупредить одной фразой и сделать по его слову.

## Как рекомендовать (порядок важности)

0. Размер лица донора по таблице выше — это фильтр, а не пожелание.
1. Пол и тип куклы — как у персонажа.
2. Раса: обычный человек — тела людей; эльф, тёмный эльф, гном, гоблин, вампир — тело этой расы (уши, рост, кожа).
   Минотавры и тролли — только для персонажей этих рас. Драконы не подходят (см. ниже).
3. Кожа тела и рук близка к коже персонажа: руки остаются донора.
4. Длина волос донора близка к волосам персонажа: новые волосы ложатся на место старых. Длинные волосы донора у
   коротко стриженного персонажа — Codex дорисует плечи, это работает, но хуже.
5. Есть шов автора (столбец «Шов») — пересадка на это тело уже проверена автором OpenYAMM.
6. Костюм — по вкусу пользователя. Только цвет ткани можно поменять без генерации (`doll.md`, раздел 7).

«Шов» — строка тела, ниже которой оно остаётся побайтно донорским, по замеру пересадок автора (`9pcNNbod` против
донора, полоса 24 px). «—» — шов определяется на листе `seams.png` (`doll.md`, раздел 2).
